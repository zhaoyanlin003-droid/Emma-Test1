## Team Launch Checklist

A dependency-free, single-file web app for tracking a launch through **Planning**, **Content**, **Approvals**, and **Launch day**.

Open `team-launch-checklist/index.html` in your browser. It includes owner assignments, saved progress, JSON export, and printing.

See [team-launch-checklist/README.md](team-launch-checklist/README.md) for local-opening instructions. No install or build step is required.

The earlier `launch-checklist` prototype remains available separately.
